# @reework/types

The shared vocabulary of [reework](https://github.com/pelerintech/reework): `Message`, `AgentEvent` (the watch
stream), `TranscriptItem`, `Proposal` / `GateDecision`, and `ROUTES` — the protocol's single route table that
the server and `@reework/client` are both built from. Types only, plus small guards.
